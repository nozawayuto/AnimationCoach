# Animation Coach v1.1

## v1.1で追加
- メールアドレスでログインできるクラウド同期
- スマホ・PC・iPad間でプロジェクト、メモ、書き込み、分析結果を共有
- 修正前・修正後・保存版の動画を非公開ストレージで同期
- 端末内保存を残したオフライン対応と、更新日時による競合防止
- Supabase Row Level Securityで自分のデータだけにアクセス

スマホ単体でリファレンス動画を1フレームずつ確認し、動画上へ書き込み、メモを管理できるPWAです。

- 保存した修正版を比較ページへ読み込んで過去版と見比べる機能

## iPhoneで使う
1. フォルダ一式をGitHub Pages、Netlify、Cloudflare PagesなどHTTPSの静的ホスティングへ配置
2. SafariでURLを開く
3. 共有 → ホーム画面に追加

## PCで試す
このフォルダ内で:
python -m http.server 8080

ブラウザで:
http://localhost:8080

## 動画書き出しについて
ブラウザのMediaRecorderを使います。
端末とブラウザにより、MP4またはWebMになります。
長い動画や高解像度動画は端末負荷が高くなるため、まず短い動画・50%解像度で試してください。

## 注意
- 自動保存では動画も端末内に保存します。大きい動画は端末の空き容量が必要です。
- 手動バックアップのプロジェクトJSONには動画を含みません。
- ブラウザの履歴・Webサイトデータを消去すると、端末内の自動保存データも消える場合があります。
- 可変フレームレート動画では、フレーム番号が概算になる場合があります。
