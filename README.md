# Animation Coach v0.3

スマホ単体でリファレンス動画を1フレームずつ確認し、動画上へ書き込み、メモを管理できるPWAです。

## v0.3で追加
- iPhone横画面に対応
- 横画面では左半分に動画、右半分に編集ボタンを配置
- 右側の編集エリアだけを縦スクロール可能に調整
- アプリ更新時に新しい画面を取得しやすいキャッシュ方式へ更新

## v0.2で追加
- 動画上へのフレーム別書き込み
- ペン / 直線 / 矢印 / 円 / 消しゴム
- 色・線幅変更
- Undo / Redo
- 書き込み付きPNG保存
- 動画・メモ・保存の3タブ
- フレーム連動メモ
- メモ検索
- メモから該当フレームへジャンプ
- 書き込み付き動画書き出し
- プロジェクトJSON保存 / 読み込み

## iPhoneで使う
1. フォルダ一式をGitHub Pages、Netlify、Cloudflare PagesなどHTTPSの静的ホスティングへ配置
2. SafariでURLを開く
3. 共有 → ホーム画面に追加

## PCで試す
このフォルダ内で:
python -m http.server 8080

ブラウザで:
http://localhost:8080

## 動画書き出しについて
ブラウザのMediaRecorderを使います。
端末とブラウザにより、MP4またはWebMになります。
長い動画や高解像度動画は端末負荷が高くなるため、まず短い動画・50%解像度で試してください。

## 注意
- 動画はプロジェクトJSONに含まれません。
- 可変フレームレート動画では、フレーム番号が概算になる場合があります。
